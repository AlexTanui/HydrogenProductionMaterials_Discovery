# Weekly meeting script (interim)

Last week, I completed the 100-epoch DimeNet++ baseline for ethanol. This week, I added performance visualizations and started a controlled experiment extending the training budget to 200 epochs. I kept the data splits, architecture, learning rate, and random seed unchanged. At this snapshot, 144 epochs have been completed, and the first 100 epochs exactly reproduce the previous run. Using the same validation selection criterion, the best checkpoint so far is at epoch 144. Energy MAE decreased from 1.634 to 1.239 kcal per mole, and force component MAE decreased from 1.564 to 1.362 kcal per mole per angstrom. These are preliminary validation improvements, not new test results. My next step is to finish the planned training and assess whether the improvements remain stable.
